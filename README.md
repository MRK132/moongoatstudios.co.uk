# MoonGoat Studios Ltd — Website

The official website of MoonGoat Studios Ltd, an independent UK software studio developing focused iPhone applications.

**Live website:** [moongoatstudios.co.uk](https://moongoatstudios.co.uk/)

## CoachGoat

CoachGoat is an iPhone running training-load tracker that compares planned and completed run distances with recent running history. Apple Health data is processed privately on-device.

CoachGoat is currently in development.

## Technical overview

This is a lightweight static website built with:

- Semantic HTML
- Custom CSS
- No JavaScript or third-party dependencies
- Responsive and accessible markup
- Structured metadata, `robots.txt` and an XML sitemap

No build step is required.

## Deployment

The `main` branch is published through GitHub Pages using the custom domain [moongoatstudios.co.uk](https://moongoatstudios.co.uk/).

HTTPS is enforced, and `www.moongoatstudios.co.uk` redirects to the canonical root domain.
